# GoreeCloud Privacy Shield — Branding

## Current identity authority

The authoritative Privacy Shield branding source is maintained in:

- Repository: `GoreeCloud/goreecloud-branding-assets`
- Canonical source: `systems/privacy-shield/privacy-shield-icon.svg`
- Local synchronized consumer derivative: `branding/privacy-shield/privacy-shield-icon.svg`

The local SVG must remain synchronized with the approved branding authority unless an intentional branding revision is separately reviewed and promoted.

## Approved current icon

The current approved icon originated from Candidate 01 and was explicitly reviewed in August 2026. It uses a rounded protective shield, a partially visible central web surface, and layered privacy bands representing filtering/interception. The design intentionally avoids forcing a conventional lettermark.

The current identity remains distinct from GoreeCloud Browser, Wardveil Security, GoreeCloud Identity, and the generic GoreeCloud platform identity.

## Usage requirements

- Derivative toolbar, monochrome, favicon, settings, documentation, and high-resolution assets must originate from the canonical SVG.
- Do not substitute inherited Browser, Wardveil, generic, placeholder, or independently redrawn artwork.
- Preserve vector-only, non-scriptable, remote-resource-free source artwork.
- Preserve compact-size legibility and light/dark presentation behavior.
- Privacy Shield branding must never be used as evidence that a capability or runtime is implemented or production accepted.

## Glaze UI

All Privacy Shield user/admin interfaces must follow the current governed Glaze UI release applicable to the platform. The current mandatory project target is Glaze UI V1.3 / 1.3.0. The retained legacy Privacy Center source still contains historical Glaze UI 2.1.0 adoption material and requires a separately validated migration before V1.3 conformance may be claimed for that surface.

## Planned Privacy Shield 2.0 identity work

A broader Privacy Shield 2.0 icon/logo/artwork refresh is planned. It is not pre-approved by the current icon acceptance. Any replacement must receive its own design, compact-size, accessibility, Glaze UI, human-review, and promotion evidence.

See `branding/privacy-shield/README.md`, `docs/IDENTITY.md`, and `docs/APPROVED-ICON.md` for implementation-facing detail.
