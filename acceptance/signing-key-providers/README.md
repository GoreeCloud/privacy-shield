# Signing-Key Provider Acceptance Records

This directory is reserved for exact-provider, exact-deployment Privacy Shield production signing-key custody acceptance records conforming to `contracts/privacy-shield.signing-key-provider-acceptance.schema.json`.

A record may be marked production-approved only when every required qualification is passed, the acceptance is fresh, the exact Privacy Shield source revision is bound, and passing evidence exists for each required qualification category.

Do not place raw private payloads, private signing material, credentials, full capability tokens, or other user-private content in acceptance evidence.

There are currently no production-approved signing-key provider records in this directory. The absence of an approved record is intentional and means Privacy Shield must not claim production signing-key custody acceptance.
