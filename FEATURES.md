# GoreeCloud Privacy Shield — Features

## Current implemented/source foundation

Privacy Shield currently provides source-level foundations for:

- shared GoreeCloud privacy capability vocabulary and machine-readable platform contracts;
- application privacy manifests, restrictive privacy policy evaluation, and authorization decisions;
- Privacy Decision Point / Privacy Enforcement Point processing;
- scoped consent, expiration, revocation, purpose limitation, processing-zone restrictions, destination restrictions, retention constraints, and external-disclosure controls;
- operation-bound capability tokens with signing-key identifiers, rotation/revocation semantics, and reusable/single-use replay policy;
- minimized privacy evidence and Privacy Receipt prototypes;
- Browser request blocking, tracker resistance, tracking-parameter cleanup, reviewed exact-match local-resource substitution, and site-exception foundations;
- privacy-safe normalized status contracts for bounded consumers;
- canonical Privacy Shield visual identity and synchronized branding derivatives;
- fail-closed repository validation and regression testing.

## Development-branch Privacy Shield 2.0 controls

The active Privacy Shield 2.0 P0 development line adds source controls for:

- transactional authority state;
- a distributed/multi-writer production state-provider contract;
- provider-neutral state-provider operational qualification;
- independent exact-provider/exact-deployment state-provider acceptance;
- opaque signing-key-provider custody with digest-only handoff and exact provider/key/producer binding;
- provider-neutral signing-key operational qualification;
- non-authorizing state/signing candidate evaluations;
- content-addressed evaluation evidence;
- governed provider evidence packages;
- attributable provider evidence-review attestations;
- provider-neutral, exact-provider/deployment access-control assessment records with fail-closed temporal and record-identity validation;
- governed provider-selection records;
- independent production acceptance records.

These are Development/source controls unless the exact provider, deployment, runtime, evidence, and acceptance record establish a higher state. There are no source-controlled production-approved state-provider or signing-key-provider records at this documentation checkpoint. There are also no provider access-control assessment records at this documentation checkpoint.

## Runtime acceptance status

GoreeCloud Browser is the privileged Firefox/Gecko runtime for Browser-specific Privacy Shield behavior. Source integration exists, but exact compiled Browser acceptance remains pending.

Other adapters are independently gated. A passing source workflow, valid adapter declaration, branding asset, dashboard presentation, or previous runtime acceptance must not be generalized into unrelated runtime acceptance.
