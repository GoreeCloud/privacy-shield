# Privacy Shield Branding Assets

This directory contains the GoreeCloud Privacy Shield visual-identity work.

## Authoritative icon path

After explicit visual approval, the canonical source must be promoted to:

```text
branding/privacy-shield/privacy-shield-icon.svg
```

Do not place provisional artwork at that path unless it has been explicitly approved as the authoritative Privacy Shield icon.

## Current candidate

The current authored candidate is:

```text
branding/privacy-shield/candidates/privacy-shield-icon-candidate-01.svg
```

Its monochrome review derivative is:

```text
branding/privacy-shield/candidates/privacy-shield-icon-candidate-01-mono.svg
```

Candidate 01 follows the approved design brief with a rounded protective shield, a partially visible central web surface, and several smooth overlapping privacy bands. The bands represent filtering and interception without using a generic checkmark, padlock, fingerprint, crossed-out eye, malware symbol, or antivirus-style threat mark.

The optional negative-space P is intentionally omitted from this first candidate rather than forcing a conventional lettermark. The symbol must work first as a privacy/filtering mark without relying on text or a letterform.

## Review requirements

Before promotion to the canonical path, explicitly review and approve:

- recognition at approximately 16–24 px;
- full-color presentation;
- monochrome presentation;
- light Glaze UI presentation;
- dark Glaze UI presentation;
- distinction from GoreeCloud Browser, Wardveil Security, and the generic GoreeCloud identity.

## Asset rules

- The approved canonical SVG becomes the source of truth.
- Derived PNG, toolbar, monochrome, favicon-sized, and other presentation assets must originate from the approved SVG.
- Do not maintain unrelated alternate designs as if they were equivalent canonical assets.
- The icon must remain distinct from GoreeCloud Browser and Wardveil Security branding.
- The icon must remain legible in compact Browser UI and in light/dark Glaze UI environments.

## Current status

Candidate 01 has been authored directly as SVG source. It is not generated artwork and is not yet the approved canonical Privacy Shield icon. Visual showcase status remains blocked until explicit approval and promotion to the canonical path.
