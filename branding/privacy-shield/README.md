# Privacy Shield Branding Assets

This directory is reserved for the canonical GoreeCloud Privacy Shield visual identity.

## Authoritative icon path

When final artwork is approved, the canonical source must be stored as:

```text
branding/privacy-shield/privacy-shield-icon.svg
```

Do not place provisional artwork at that path unless it has been explicitly approved as the authoritative Privacy Shield icon.

## Asset rules

- The SVG is the source of truth.
- Derived PNG, toolbar, monochrome, favicon-sized, and other presentation assets must originate from the approved SVG.
- Do not maintain unrelated alternate designs as if they were equivalent canonical assets.
- The icon must remain distinct from GoreeCloud Browser and Wardveil Security branding.
- The icon must remain legible in compact Browser UI and in light/dark Glaze UI environments.

## Current status

The icon design brief is approved as documentation, but final icon artwork has not yet been generated or approved.
