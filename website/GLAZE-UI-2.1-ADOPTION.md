The Privacy Center follows the Glaze UI 2.1 material rule **Content is solid. Interaction is glazed.** Durable protection, boundary, principle, evidence, and status content uses solid Surface material. Navigation and appropriate transient interaction may use controlled glaze.

The website carries the 48px general interaction floor, 56px Touch Assistance floor, density and clarity behavior, large-text fallback, reduced-motion and reduced-transparency handling, increased/forced-contrast resilience, and deterministic reduced-material behavior.

Glaze UI controls presentation only. It does not manufacture Privacy Shield protection, browser acceptance, current evidence, Wardveil Security state, or Mesh state. Existing Glaze UI 2.0 documentation is retained only as a historical adoption record; it does not remain an active public dependency after 2.1 deployment acceptance.
