# Privacy Center — Glaze UI 2.0.0 adoption

Privacy Center targets **Glaze UI 2.0.0 Stable** from `GoreeCloud/goreecloud-glaze-ui`, pinned to promotion revision `ff3fff4306bd53ea9c0715a7c0d64265bb038617`.

The deployed web subset contains only the Stable contracts exercised by Privacy Center: Soft Glaze material behavior, Appearance and Clarity state, Navigation Capsule focus/target semantics, 48 px interactive target floors, reduced-motion substitution, reduced-transparency solid fallback, increased-contrast handling, and forced-color fallback.

This adoption changes presentation only. Privacy Shield remains authoritative for privacy state, consent, data-minimization policy, and evidence. Glaze UI cannot create or strengthen a privacy-protected claim.

Rendered/platform acceptance remains separate from source validation and must be evidenced before this site is used as proof of broader Glaze UI portfolio conformance.
