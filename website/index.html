Privacy by Default

Protection that belongs to the browser.

GoreeCloud Privacy Shield is the first-party privacy and content-protection subsystem for GoreeCloud Browser. It provides native blocking, tracking-parameter cleanup, local protection logic, compatibility controls, and understandable protection status without making a third-party extension the core privacy experience.

First-partyLocal-firstGlaze UINo remote telemetry learning
Core responsibilities

Privacy controls with clear boundaries.

Request blocking

Native ad and tracker request blocking provides a GoreeCloud-owned protection layer within the Browser model.

Tracking cleanup

Tracking parameters can be removed before navigation while preserving normal browsing behavior.

Local protection

Behavioral tracker learning remains local and session-scoped in the portable core. Remote tracker learning is not part of the approved contract.

Compatibility controls

Per-site exceptions and compatibility handling are designed to preserve understandable, reversible user control.

Reviewed substitution

Local-resource substitution remains exact-match only and fails open to the original network request.

Protection reporting

Privacy status is intended to be understandable rather than hidden behind opaque security language.

What Privacy Shield is — and is not

Browser privacy, not a replacement for browser security.

Privacy Shield

Browser-specific privacy and content protection: blocking, cleanup, local protection behavior, exceptions, reporting, and native privacy controls.

GoreeCloud Browser

The browser application and privileged Firefox/Gecko runtime authority.

Wardveil Security

The platform-wide security and protection identity for GoreeCloud.

Privacy Shield does not replace or weaken Safe Browsing, TLS, certificate validation, sandboxing, process isolation, site permissions, or the application update system.

Privacy principles

Designed to minimize unnecessary data exposure.

Local by defaultProtection logic does not require remote behavioral learning.
Understandable controlsExceptions and protection state should remain visible and reversible.
Dependency reductionThe core experience is designed to avoid dependence on a third-party blocking extension.
Layered protectionPrivacy Shield complements, rather than replaces, DNS filtering and browser security mechanisms.
